# ADR 0008: 코드 주석 영어화 — 주석·진단 문자열·테스트 식별자를 영어로 통일

## Status

Accepted (2026-09-22)

## Context

DS_MessageProtocol은 Unity / .NET 개발자가 소비하는 공개 라이브러리다. 라이브러리 사용자는 IntelliSense와 생성된 API 문서를 통해 XML doc 주석(`///`)을 읽고, 샌드박스 예제와 테스트를 참조해 사용법을 익힌다. 그런데 기존 코드의 주석 1,550여 줄과 테스트 메서드명 259개, 테스트 진단 메시지가 한국어로 작성되어 있어 한국어를 읽지 못하는 사용자는 라이브러리를 이해하기 어려웠다. 문서 vault(`Document/`)는 한국어로 유지하되, 코드에 포함된 텍스트는 라이브러리 소비자 언어와 일치시킬 필요가 있었다.

## Decision

1. **모든 코드 주석(`//`, `///` XML doc)은 영어로 작성한다.** 라이브러리 소비자 관점에서 쓴다 — `///`는 IntelliSense에 노출되는 API 계약(첫 줄은 완결된 한 문장), `//`는 코드가 "무엇을" 하는지가 아니라 "왜" 그렇게 하는지를 설명한다.
2. **테스트의 한국어 진단 문자열과 한국어 테스트 메서드명도 영어로 바꾼다.** 테스트 실패 메시지는 유지보수자에게 노출되는 진단 출력이고, 메서드명은 테스트 리포트에서 동작 명세로 읽힌다.
3. **예외 — 인코딩 검증용 페이로드 데이터는 한국어를 유지한다.** `"한글·日本語·🌟"` 등 비ASCII 직렬화 왕복을 검증하는 테스트 입력값은 의도된 데이터이며, 각 리터럴 옆에 그 의도를 밝히는 영어 주석을 붙인다.
4. **범위 밖** — `Legacy/`(읽기 전용 아카이브), `obj/`·`bin/` 빌드 산출물, `Document/` 볼트(한국어 유지), 코드 로직·와이어 포맷·공개 API 시그니처(주석 언어 전환과 무관하게 무변경).

## Consequences

- 2026-09-22 기준 Source/Test/Sandbox의 한국어 주석·진단 문자열·테스트 메서드명이 전면 영어화된다. 코드 로직은 무변경이며 빌드·전체 테스트로 동등성을 검증한다.
- 이후 작성되는 모든 주석은 영어로 쓴다 — [CONVENTIONS](../00-AI/CONVENTIONS.md)의 "코드 주석" 규약으로 고정.
- `Document/` 볼트와 커밋 메시지 정책은 본 결정의 대상이 아니다(한국어 유지).
